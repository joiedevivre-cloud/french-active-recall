## 0. 역할, 목표, 최우선 원칙

당신은 **시니어 풀스택 개발자이자 프랑스어 학습 시스템 설계자**입니다.

React, TypeScript, PostgreSQL, Supabase, AI API, 음성 인식, 간격 반복 학습 시스템을 활용하여 **실제로 사용 가능한** 프랑스어 학습 웹앱을 개발하세요.

- 설계 문서나 예시 코드만 작성하고 끝내지 마세요. **실행 가능한 MVP를 구현하는 것이 목표**입니다.
- 설계만 제시하고 종료하지 말고, 사용 가능한 환경에서 **Phase 1부터 실제 구현**을 진행하세요.
- 구현 중 기능이 누락되거나 오류가 발생하면 **임시로 작동하는 것처럼 표시하지 마세요.** (가짜 성공 메시지, 하드코딩된 결과, mock을 실제 기능처럼 보이게 하는 것 금지)
- 실제 GitHub 및 Supabase 접근 권한이 없는 경우 **배포 완료라고 주장하지 말고**, 필요한 연결 또는 승인 절차를 안내하세요.

**최우선 목표:**
사용자가 프랑스어 수업 중 모르는 표현을 **10초 이내에 저장**하고, 수업이 끝난 후 그 표현을 **자동 복습**하며, 실제 프랑스어 대화에서 **스스로 꺼내 사용**할 수 있는 앱을 만드는 것.

**핵심 원칙:** 표현 수집은 빠르게, 학습은 깊게, 복습은 자동으로.

**학습 흐름:** Capture → Understand → Recall → Conversation → Spaced Review

## 1. 프로젝트 목적과 사용자

이 앱은 프랑스어 **A2~B2 학습자**가 학교 수업, 일상 대화, TV5MONDE, 뉴스, 영상 등을 통해 새롭게 접한 프랑스어 표현을 즉시 수집하고, 반복적으로 기억하고, 실제 대화에서 자연스럽게 사용할 수 있도록 돕는 **개인 학습 시스템**입니다. 또한 **림박 B2 700문장 공부법**을 디지털화하여 DELF B2 합격까지 가속하는 모듈을 포함합니다.

사용자는 **몬트리올**에서 프랑스어를 공부하고 있으며, 다음 어려움이 있습니다.

- 프랑스어를 들으면 단어는 인식하지만 의미를 즉시 이해하지 못할 때가 있음
- 배운 표현을 실제 말하기에서 빠르게 꺼내지 못함
- 새로운 표현을 자주 찾지만 체계적으로 누적·복습하기 어려움
- 한국어를 프랑스어로 번역하는 방식에 지나치게 의존하고 싶지 않음
- 학교에서 배운 표현을 그날 바로 복습하고 싶음

## 3. 기술 스택 및 배포 아키텍처

| 영역 | 구성 |
|---|---|
| Frontend | React + TypeScript + Vite |
| UI | Tailwind CSS (다크 모드 지원) |
| Hosting | **GitHub Pages** |
| CI/CD | **GitHub Actions** |
| Database | Supabase PostgreSQL |
| Authentication | Supabase Auth |
| Backend | **Supabase Edge Functions** (FastAPI 사용 안 함, GitHub Pages에 Python 서버 배포 금지) |
| AI | Supabase Edge Functions에서 서버 측 LLM API 호출 |
| Speech-to-text | 프랑스어 지원 음성 인식 API (서버 측) — 무료 대안/보조로 Web Speech API Recognition 사용 가능 |
| Text-to-speech | 프랑스어 음성 합성 API (원어민에 가까운 음성). 폴백으로 브라우저 Web Speech Synthesis |
| OCR | 사진 촬영 → OCR (서버 측 또는 클라이언트 OCR, 결과 수정 가능) |
| Spaced repetition | **FSRS** (예: `ts-fsrs` 라이브러리) |
| Offline | IndexedDB + PWA (Service Worker) |

### Supabase 프로젝트
- 사용자는 **이미 Supabase 계정이 있습니다. 새 계정을 만들 필요가 없습니다.**
- 가능하면 **앱 전용 Supabase 프로젝트**를 사용하세요.
- 기존 프로젝트를 공유해야 한다면 **별도 스키마**와 적절한 접근 정책을 설계하세요.
- Supabase 프로젝트 URL과 공개용 키는 **환경변수**로 설정하세요.

## 4. 가장 중요한 기능 — 빠른 표현 저장

앱 홈 화면에서 가장 눈에 띄는 기능은 **[+ 표현 추가]** 버튼이어야 합니다. 학교 수업 중에는 **몇 초 안에(목표 10초 이내)** 표현을 저장할 수 있어야 합니다.

### 4-1. 입력 방법
1. 직접 텍스트 입력
2. 마이크로 프랑스어 표현 말하기
3. 사진 촬영 및 OCR
4. 복사한 문장 붙여넣기

### 4-2. 앱 처리 (예: 사용자 입력 "relever un défi")
- 원문을 **즉시 저장**
- AI가 표현의 **기본형(lemma)과 의미** 분석
- 한국어 뜻 제공
- 쉬운 프랑스어 정의 제공
- 자연스러운 예문 생성 (+ 예문 한국어 번역)
- 원어민에 가까운 프랑스어 음성 재생
- 품사 및 문법 설명
- 관련 표현 제공
- CEFR 수준 추정
- 복습 목록 자동 등록

결과 예시:
```
표현: relever un défi
한국어: 도전에 나서다
Définition simple: Accepter de faire quelque chose de difficile.
Exemple: J'ai décidé de relever un nouveau défi.
한국어: 나는 새로운 도전에 나서기로 결심했다.
```

### 4-3. 핵심 요구사항
- AI 분석을 **기다리지 않고 원문부터 저장**
- 저장 직후 다른 표현을 **계속 입력 가능**
- **중복 표현 감지**
- AI 분석 결과 **수정 가능**
- 입력한 **원문과 AI 생성 정보를 구분하여 저장**
- 문맥에 따라 의미가 달라지면 **여러 뜻 지원**
- 사진 및 음성 인식 결과 **수정 가능**
- **네트워크 오류가 발생해도 입력 내용 보존**

### 4-4. 저장 후 버튼
- **[저장하고 끝내기]**
- **[지금 연습하기]**

수업 중에는 저장만 하고 나중에 복습할 수 있어야 합니다.

## 7. 인출 훈련 (Active Recall)

이 앱의 핵심은 Recognition이 아니라 **Active Recall**입니다. 다음 네 가지 훈련을 지원하세요.

### A. 의미 인출
프랑스어 표현을 보고 의미를 떠올립니다.

### B. 빈칸 인출
```
J'ai décidé de ______ un nouveau défi.
정답: relever
```

### C. 상황 기반 인출
```
상황: Vous voulez changer de travail.
질문: Pourquoi voulez-vous changer de travail ?
```
사용자가 프랑스어로 직접 답합니다.

### D. 음성 인출
사용자가 마이크로 프랑스어 문장을 말하면 시스템이 다음을 분석합니다.
- 의미 전달 여부
- 문법 정확성
- 목표 표현 사용 여부
- 응답 시간
- 힌트 사용 여부

### 인출 훈련 공통 규칙
- 기본 학습에서는 **한국어 번역을 먼저 보여주지 마세요.**
- **프랑스어 질문과 상황을 먼저** 제공합니다.
- 이해하지 못하면 **한국어 힌트를 선택**할 수 있습니다.
- 정답과 동일한 문장을 말하지 않아도 **자연스럽고 의미가 맞으면 인정**합니다.
- 답변 전에는 **정답 표현을 노출하지 않습니다.**
- 처음에는 충분한 시간을 주고 **점차 반응 속도를 높입니다.**
- 음성 인식 오류와 실제 문법 오류를 구분할 수 있도록 **인식된 원문 수정 기능**을 제공합니다.

## 8. AI 상황 대화

학습한 표현을 실제 상황에서 사용하도록 AI 대화 기능을 구현하세요.

사용자가 최근 저장했거나 복습이 필요한 표현 **3~5개를 선택**합니다.

상황 예시:
- 프랑스어 학교에서 선생님에게 질문하기
- 친구와 주말 계획 이야기하기
- 직장에서 동료와 문제 해결하기
- 취업 면접
- 병원 예약
- 전화 문의
- 몬트리올 일상생활

예시:
```
AI: Pourquoi souhaitez-vous changer de poste ?
사용자: Je voudrais relever un nouveau défi professionnel.
AI: Quel genre de défi aimeriez-vous relever ?
```

대화 규칙:
- AI는 사용자의 **CEFR 수준에 맞춰** 말합니다.
- 목표 표현을 **정답처럼 미리 제시하지 않습니다.**
- 사용자가 자연스럽게 표현을 사용할 **기회를 만듭니다.**
- 답변마다 **지나치게 교정하지 않습니다.**
- 대화 종료 후 주요 오류를 정리합니다.
- 학습자가 사용하지 못한 표현을 **다음 복습에 반영**합니다.
- **3~5턴 대화**부터 시작합니다.

대화 완료 후 결과:
- 성공적으로 사용한 표현
- 사용하지 못한 표현
- 반복된 문법 오류
- 더 자연스러운 문장
- 다음 복습 추천

## 9. 자동 간격 반복 복습 (FSRS)

- 표현을 저장하면 **자동으로 학습 대기 목록**에 추가합니다.
- **첫 학습 완료 후** 복습 일정을 계산합니다.

사용자별 기록 항목:
- 마지막 복습 시각
- 다음 복습 시각
- 기억 난이도
- 복습 횟수
- 정답 여부
- 응답 시간
- 힌트 사용 여부
- 실제 대화 사용 여부

복습 방식:
1. 프랑스어 의미 확인
2. 빈칸 완성
3. 상황 질문에 답하기
4. 실제 대화에서 사용하기

규칙:
- 기억하지 못하면 **더 빨리** 복습하도록 합니다. (자료 B: 틀린 문장은 **즉시 오늘 세션에 재출제** + 간격 리셋 → FSRS `Again` + 세션 내 재출제 큐로 구현)
- 쉽게 기억하는 표현은 **복습 간격을 늘립니다.**
- 넘긴(skip) 문장은 **별도 복습 세션**으로 모읍니다. (자료 B)
- **FSRS 상태 갱신은 명확한 복습 평가(Again/Hard/Good/Easy)를 기준**으로 하고, 응답 시간이나 AI 대화 결과를 **임의의 점수로 직접 치환하지 마세요.** (응답 시간·힌트·AI 피드백은 기록과 평가 제안용으로만 사용하고, 최종 평가는 사용자가 확정)

하루 학습 목표 (기본값, **모두 사용자 설정에서 변경 가능**):
- 신규 표현 5~8개
- 기존 표현 10~15개
- AI 상황 대화 5분
- (B2 700문장 모드) 일일 문장 수 10~50개 범위에서 설정

## 10. B2 700문장 모듈 (림박 공부법) — 자료 B

### 10-1. 핵심 철학
- **"문장 통째로 외워라"** — 단어/문법 분리 학습이 아님.
- B2 수준 고빈도 문장 **700개를 완전히 체화**할 때까지 반복.
- 한국어 뜻을 보고 → 프랑스어로 **즉각 출력**하는 능력 훈련 (이 모듈 한정 기본값, 0-1 참조).
- 목표: **700문장 100% 즉각 출력**, DELF B2 합격.
- 타겟: A2~B1 보유자, B2 목표, 독학 학습자.

### 10-2. 학습 방법론
1. **패턴별 문장 학습**: 문장을 패턴으로 분류(동사 활용: subjonctif, conditionnel, infinitif 등 / 연결어·접속사: bien que, afin que…), 같은 패턴을 다른 문장에 적용 연습
2. **입력 → 출력 루프**: STEP 1 한국어 보기 → STEP 2 프랑스어 말하기/쓰기 시도 → STEP 3 정답 확인 & 발음 듣기(TTS) → STEP 4 틀린 문장 집중 복습
3. **반복 간격 학습**: 맞춘 문장 간격 늘려 재출제 / 틀린 문장 즉시 재출제(복습 큐) / 넘긴 문장 별도 복습 세션
4. **쉐도잉 연계**: 문장 암기 후 TTS 발음 확인 → 원어민 속도로 따라 읽기 → 단어 빈칸 채우기로 청취력 강화 → écoute 훈련으로 B2 청취 도달

### 10-3. 문법 카테고리 (6개 패턴 태그)
| 카테고리 | 예시 패턴 | 비중 |
|---|---|---|
| Subjonctif | bien que + subj / pour que + subj | ~20% |
| Conditionnel | si + imparfait → conditionnel | ~15% |
| Infinitif / Gérondif | en + participe présent | ~15% |
| Relatif complexe | dont / auquel / ce qui / ce que | ~15% |
| Passé composé / Imparfait | 과거 시제 대조 | ~20% |
| Expression idiomatique | 관용표현·어휘 B2 | ~15% |

### 10-4. 데이터
- 700문장 **내장 JSON** (필드: 질문(한국어)/정답(프랑스어)/패턴 태그/레벨) + 사용자 추가 CSV
- 앱 부팅(또는 최초 로그인) 시 700문장 **자동 로드** — CSV 업로드 없이 바로 시작
- 기존 CSV 데이터와 **병합 가능**
- ⚠️ **700문장 원본 데이터는 제공되지 않았습니다.** 문장을 AI로 임의 생성해 "림박 700문장"인 것처럼 넣지 마세요. 사용자가 CSV/JSON을 제공할 때까지는 **스키마·임포터·빈 상태 UI**만 구현하고, 필요한 파일 형식을 README에 안내하세요.
- 700문장 항목도 개인 표현장과 같은 FSRS(`review_states`) 체계로 관리하되, `source_type = 'b2_700'`과 패턴 태그로 구분하세요.

### 10-5. 학습 모드 (3가지)
- 🧠 **퀴즈 모드**: 한국어 → 프랑스어 타이핑 (기존 기능 유지·강화)
- 🎧 **에코트(écoute) 모드**: TTS 듣기 → 받아쓰기 → 단어 공개 (기존 기능 유지)
- 🔁 **쉐도잉 모드**(신규): 문장 보기 → TTS → 내 목소리로 따라 읽기 → 음성 비교
  - Web Speech API Recognition(또는 서버 STT)으로 내 발음을 텍스트로 변환
  - 원문과 내 발음 텍스트 **비교 채점**
  - 속도/발음 트레이닝: **0.7x → 1.0x → 1.3x**
- 오답 문장 → **에코트 세션 자동 연결** (기존 Export 기능 유지)

### 10-6. 패턴 학습 시스템
- 700문장을 6개 문법 카테고리로 태그 분류
- **카테고리별 진도율** 개별 표시
- 패턴 힌트 카드 (출제 시 1줄 문법 요약, 옵션)
- **같은 패턴의 연관 문장 모아보기** / 필터링
- 카테고리별 취약 분석

### 10-7. 홈 대시보드 (B2 섹션)
- 오늘의 학습 목표 (일일 문장 수 10~50개 설정)
- **B2 도달 예측일** (현재 진도율 기반 자동 계산, 계산식은 화면에 설명)
- **B2 목표일 설정 + 진도율**
- 700문장 전체 진행 **링 차트** (Mastered / Learning / New)
- **연속 학습일 스트릭** 🔥
- **오늘의 취약 패턴 추천** (가장 많이 틀린 문법 카테고리)

### 10-8. 통계 & 진도 관리
- 일별 학습 문장 수, 정답률, 학습 시간 그래프
- 문장별 시도 횟수, 정답률, 다음 복습일
- 패턴별 취약 분석 **레이더 차트**
- **B2 준비도 점수 (0~100%)** = 정확도 + 복습 완료율 + 범위 커버리지 (가중치는 설정·문서화)

- 로그인 후 **원래 앱(원래 화면)으로 정상 복귀**하도록 설정

## 19. 테스트 및 완료 기준

### 19-1. 기능 시나리오 (반드시 검증)
1. 모바일에서 표현을 입력하고 저장할 수 있다. (10초 이내 저장 목표)
2. 저장한 표현이 Supabase에 정상적으로 저장된다.
3. 페이지를 새로고침해도 표현이 유지된다.
4. AI 분석 결과를 확인하고 수정할 수 있다.
5. 오늘 저장한 표현을 모아서 복습할 수 있다.
6. 한국어를 보지 않고 프랑스어 상황에서 인출할 수 있다.
7. 복습 결과가 저장되고 다음 복습일이 계산된다.
8. AI 대화에서 학습한 표현을 사용할 수 있다.
9. 다른 사용자의 데이터에 접근할 수 없다. (RLS 테스트)
10. 오프라인에서 저장한 표현이 연결 복구 후 동기화된다.
11. (B2) 700문장 데이터 임포트 후 패턴별 학습·진도율·틀린 문장 즉시 재출제가 동작한다.

### 19-2. 배포 완료 조건
- GitHub 저장소에 소스 코드 업로드
- GitHub Actions 빌드 성공
- GitHub Pages URL 정상 접속 (직접 URL 접근·새로고침 시 404 없음)
- Supabase 로그인 성공 (로그인 후 앱으로 복귀)
- 표현 저장 및 조회 성공
- 모바일에서 PWA 설치 가능
- AI API 키가 브라우저(번들·네트워크 요청)에 노출되지 않음
- 새 코드 push 시 자동 재배포

### 19-3. 보고 방식
- **자동화 테스트와 수동 테스트 결과를 구분하여 보고**하세요.
- 검증하지 못한 항목은 "미검증"으로 명시하고 이유를 적으세요.

## 22. 금지 사항 요약 (체크리스트)

- [ ] 기존 프로젝트·저장소·Supabase 데이터를 승인 없이 삭제/덮어쓰기/파괴적 변경하지 않았다
- [ ] `.env`, 비밀키, DB 비밀번호, 사용자 데이터를 커밋하지 않았다
- [ ] service role key / AI API key가 프런트엔드·번들에 없다
- [ ] GitHub Pages에 Python/FastAPI 서버를 배포하지 않았다
- [ ] 실패한 빌드가 배포되지 않는다
- [ ] 미구현·오류 기능을 작동하는 것처럼 표시하지 않았다
- [ ] 응답 시간·AI 대화 결과를 FSRS 점수로 임의 치환하지 않았다
- [ ] 인출 훈련에서 답변 전 정답/한국어 번역을 먼저 노출하지 않았다 (B2 700문장 모드의 한→프 출제는 예외로 설정 가능)
- [ ] 700문장 데이터를 임의로 생성해 원본인 것처럼 넣지 않았다
- [ ] 권한 없이 배포 완료를 주장하지 않았다

**설계만 제시하고 종료하지 말고, 먼저 현재 프로젝트 구조를 분석하고 구현 계획을 작성한 뒤 Phase 0 → Phase 1부터 실제 구현을 진행하세요.**
